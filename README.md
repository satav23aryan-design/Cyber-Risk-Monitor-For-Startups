# AI Cyber Risk Monitoring System

## Overview

The AI Cyber Risk Monitoring System is a machine learning-based web
application that analyzes cybersecurity datasets and predicts risk
levels. The system allows users to upload datasets, train machine
learning models automatically, and visualize cyber risk analytics
through an interactive dashboard.

The application is built using Streamlit and Scikit-learn, enabling
users to perform cybersecurity risk prediction without writing any code.

------------------------------------------------------------------------

## Features

-   Secure user login system
-   Upload cybersecurity datasets (CSV format)
-   Automatic machine learning model training
-   Model comparison and accuracy evaluation
-   Cyber risk score generation
-   Risk level classification (Low, Medium, High)
-   Interactive charts and visual analytics
-   Startup risk category analysis

## Installation

Clone the repository and install the required dependencies.

pip install -r requirements.txt

------------------------------------------------------------------------

## Run the Application

Start the Streamlit application using the following command:

streamlit run app.py

The application will open in the browser:

http://localhost:8501

------------------------------------------------------------------------

## How It Works

1.  User logs into the system.
2.  User uploads a cybersecurity dataset.
3.  The system automatically trains multiple machine learning models.
4.  The best performing model is selected.
5.  Cyber risk levels are predicted.
6.  Results are displayed through an interactive dashboard.
